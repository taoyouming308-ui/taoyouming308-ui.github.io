# Salon Core

独立门店经营系统的领域边界。开发阶段不接入现有员工端、前台或悦西智营，也不写美管加。

第一阶段对象：组织、门店、角色、员工、顾客、项目/商品、预约、订单、会员账户、账户流水、支付和审计。

规则：

- 所有业务数据必须带组织范围；门店业务同时带门店范围。
- 资金、次数、支付和审计只追加，禁止覆盖历史；纠错使用反向流水。
- 订单是预约、到店、服务、收银、业绩和日报的主链。
- 浏览器不直接获得业务表写权限；正式接口统一由后续 `salon-api` 校验会话、角色和门店。
- 本模块通过全部离线测试以前不得迁移生产数据库或接入现有三个板块。

本机接口联调入口和测试边界见 `../../docs/salon-local-api-workbench.md`。`api-client.mjs` 提供显式接口、门店上下文、字段映射与冻结请求重试；目前仅接入独立联调工作台，不代表原 13 模块已经切换到正式接口。
