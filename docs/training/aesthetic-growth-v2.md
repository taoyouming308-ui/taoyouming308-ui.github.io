# 美感成长 V2

## 产品目标

每次训练必须让员工带走一个新知识、一个观察方法和一个顾客沟通技巧。系统奖励认知升级，不奖励机械完成。

## 每日变化

- 根据员工最低能力维度选择今日挑战；
- 在美学、技术、顾客、反证和大师五种导师模式间变化；
- 同一案例继续复用 Hair Vision 的人物镜头、相邻风格、结构、适配和异议轮换；
- 连续完成七天时进入隐藏 Boss，要求同时给出证据与反证。

## 掌握标准

检查点不能因为员工回答过而完成。只有回答至少包含两个位置明确的有效证据，并建立“证据 → 判断 → 设计影响”的关系，服务端才标记 `mastered`。否则保持 `incomplete`，AI缩小观察范围继续追问。

## 长期成长档案

档案记录五项能力、重复误判、大师洞察历史、成长标签、大师值和最近100次突破。当前设备保存即时副本，每次 Session 同步到受 RLS 保护的训练记录；新设备读取最近云端快照。

## 结束输出

- 今天最大的顿悟；
- 新知识；
- 新观察方法；
- 顾客沟通技巧；
- 今天的成长标签；
- 今天击败昨天；
- 下次挑战。

大师洞察必须针对本次具体盲点，并避开历史已出现的句子。AI仍不得根据外貌推断真实职业、性格、消费能力或其他不可见事实。
