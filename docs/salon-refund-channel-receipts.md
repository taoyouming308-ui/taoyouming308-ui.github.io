# 退款外部渠道回执核验

状态：仅独立开发分支和合成 PostgreSQL 测试；没有应用远程迁移、连接支付渠道或处理真实业务款项。

## 本批规则

- 退款申请批准不等于渠道已退款。现金、微信、支付宝、银行卡等外部渠道分配，执行前必须有渠道凭证引用和说明，并由不同员工复核。
- 登记、通过、拒绝均追加新版本；记录原退款分配金额、凭证引用、说明、登记/复核人和时间。复核必须针对登记的同一凭证，且不能由登记人自审。
- 数据库退款执行器只接受“最新版本为 verified 且金额与当前分配完全一致”的回执；任一外部支付未核验则整笔事务回滚，不写反向支付、会员流水、库存或订单退款总额。
- 该功能只记录本地核验结果，不调用微信/支付宝/银行 API，也不能证明外部渠道本身真实完成了退款。凭证引用不要填写银行卡号、账号、手机号等敏感信息。
- 会员储值/次卡退款是独立内部账务链，本批不要求外部凭证，也未开放执行 UI。
