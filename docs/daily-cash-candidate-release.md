## 用户确认与填写公式

2026-09-28 用户确认“1”选择全部真实外部收款，继而确认“充值、套餐、年卡新收的钱不计实做”。本轮不改已入账日报，也不按新口径重算向里一月份的历史账。

- `实做 = 现金流 = 项目＋零售的真实外部收款`，包括现金、微信、支付宝、点评和抖音等。对应源 incomeType `[1,2]` 的现金类总额，不以员工分配业绩代替。
- `卡类小计 = 充值＋套餐＋年卡的独立现金汇总`（incomeType `[3,4,5]`）。它仅表示新收现金，不是储值卡扣款、赠送金或套餐核销。全业务减经营收款仅可作核对，不能作为售卡金额来源，避免两次读取之间新增项目收款被误分类。
- `汇总总计 = 支付总计 = 实做 + 卡类新收款小计`。这是外部收款合计，不是月报经营收入；月报既有收入读取现金流，不读取售卡总额。
- 支付渠道栏对应经营收款；售卡新收款另列。不能猜测三种售卡收入与疗程卡/资格卡/会籍卡的逐一对应，因此仅补来源有证据的卡类小计，分类不足保留待核对。
- 四个公/私刷卡、支微列不自动填写。银联/商场卡/合作券/口碑不能猜映射；非零时标记缺口并阻断收款校验通过。
- 原源未知仍为 NULL；有明确的源零才可填写零。员工内部业绩小计继续校验，技师仍只计烫染护个数，褪色和染发同次同客算一次。
